## Где живёт сайт (важно: не на Beget)

Файлы сайта лежат **в этом репозитории** и публикуются через GitHub Pages: каждый коммит в ветку `main` обновляет сайт за 1–3 минуты.

На **Beget** сайта нет — там только доменная запись. Посмотреть её: [cp.beget.com](https://cp.beget.com) → «Домены и поддомены» → `getpublish-io.ru` → поддомен `neiroseti` → DNS‑запись CNAME → `goncharenkoser-dot.github.io`. Править на Beget ничего не нужно; основной домен `getpublish-io.ru` занят игрой «Архитектор книги» и его не трогаем.

Адрес сайта в GitHub: репозиторий → Settings → Pages (https://github.com/goncharenkoser-dot/neiroseti/settings/pages).

## Как внести правки через Claude Code

1. Принять приглашение в репозиторий: https://github.com/goncharenkoser-dot/neiroseti/invitations (права на запись уже выданы).
2. Один раз скачать репозиторий на компьютер:
   ```bash
   git clone https://github.com/goncharenkoser-dot/neiroseti.git
   ```
   (или попросить Claude Code: «склонируй https://github.com/goncharenkoser-dot/neiroseti и открой папку»).
3. Открыть папку `neiroseti` в Claude Code и написать задачу словами, например:
   «Перед работой сделай git pull. На лендинге в блоке „Что будет на эфире“ замени текст второй карточки на … Покажи изменения, закоммить и отправь в main».
4. Claude правит `index.html` или `thanks.html`, делает коммит и `git push`. Через 1–3 минуты правка на сайте. Проверить — открыть адрес и обновить страницу с очисткой кеша (Ctrl+Shift+R / Cmd+Shift+R).

Без Claude: открыть файл на GitHub → значок карандаша → внести правку → «Commit changes» (в ветку `main`). Сайт обновится так же.

## Правила

- Перед работой — `git pull`, чтобы не затереть чужие правки.
- Тексты лендинга согласованы с Георгием: формулировки, цифры и фраза «Никаких продаж — только ИИ‑инструменты для писателей» не меняются без согласования.
- Форма регистрации — виджет GetCourse, встроен скриптом; поля, кнопку и переход на страницу «спасибо» настраивают в GetCourse, а не в HTML.
- После правок написать Сергею: он подтянет изменения в основной репозиторий проекта (`getpublished-ai-course`, папка `02-прогрев/лендинг`) и в копию для Тильды (`getpublished-landing-neuroseti`).
